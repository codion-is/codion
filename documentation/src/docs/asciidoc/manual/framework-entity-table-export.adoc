[#_table_export]
= Exporting data
:url-javadoc: link:../api

The table export tool produces denormalized, tab-separated output from the rows of an {url-javadoc}{swing-framework-ui}/is/codion/swing/framework/ui/EntityTablePanel.html[EntityTablePanel] — to the clipboard or to a file — and is available via *Export...* in the table popup menu.

What sets it apart from a plain copy is *foreign key traversal*: the export dialog presents the entity's attributes as a tree, where each foreign key expands into the attributes of the referenced entity, recursively.
Including *Track → Album → Artist → Name* exports the artist name as a column alongside the track's own attributes — denormalized flat output from normalized data, without writing a query.

== Using it

* Attributes are checked in the tree, by clicking their check box or with SPACE, SHIFT-SPACE checking the attributes below a foreign key, and a search field filters the tree by caption.
* The checked attributes are listed beside the tree, as the columns in the order of the export, moved by dragging or with ALT-Up/Down and removed with DELETE. A checked attribute goes after the last column from the same foreign key, otherwise last, while a column of a referenced entity can be moved anywhere, not only next to its foreign key.
* Each column has a header, the captions on its path by default, edited in place with F2 or a double-click and saved with the configuration.
* The columns default to the visible table columns, in the table's order.
* Foreign key nodes expand on demand, so cyclic references are a non-issue — expansion goes as deep as you take it.
* The export covers the *selected* rows or *all* rows.
* Output goes to the clipboard or a *.tsv* file, ready for a spreadsheet.

== Configurations

An export configuration — the included attributes and their order — can be *named, saved and opened later*, and reappears in the export dialog as long as the configuration file exists.
The active configuration is saved in user preferences on application exit, so a routinely used export is a two-keystroke affair.

== Enabling

The export tool is excluded by default, and enabled globally via the {url-javadoc}{swing-framework-ui}/is/codion/swing/framework/ui/EntityTablePanel.Config.html#INCLUDE_EXPORT[EntityTablePanel.Config.INCLUDE_EXPORT] configuration value or per panel:

[source,java]
----
EntityTablePanel.Config.INCLUDE_EXPORT.set(true);
----

The underlying model, {url-javadoc}{framework-model}/is/codion/framework/model/EntityExport.html[EntityExport], is UI-independent and can be used to produce the same output programmatically.
